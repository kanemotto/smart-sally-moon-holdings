# Smart Sally Moon Holdings

A focused US stock scalp dashboard built for quick 2–3% trade decisions.

## Features

- Live US stock price data
- Editable ticker watchlist saved on-device
- Ideal entry zones
- +2% and +3% take-profit targets
- Stop, support, resistance, RSI, volume ratio, and trend
- Enter / Wait / Take Profit / Avoid signals
- Mobile-friendly layout
